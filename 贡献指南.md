# 贡献指南

## 中文

欢迎通过问题反馈或 Pull Request 改进 Flash Mask。请让每个 PR 聚焦于清楚的一项改动，并说明它解决的问题。

提交前可按改动范围运行相应检查：

- 核心测试需要 Node.js 22：运行 `npm ci --ignore-scripts`，再运行 `npm test`。
- Mac App 通用构建需要安装 Xcode 的 Mac：运行 `./build.sh`，再运行 `bash .github/scripts/verify-mac-build.sh` 核验产物。构建为未签名的本地 App，不需要 Apple 签名证书，也不会分发 App。
- Mac 本地界面测试可单独运行 `node --test tests/mac-localization-ui.js`。它会打开隔离的测试窗口，使用合成图片、独立偏好和剪贴板替身；不属于默认 `npm test` 或 CI 检查。

GitHub Actions 会在所有目标分支的 Pull Request、推送到 `main` 和手动触发时运行两项检查：Ubuntu 24.04 上使用 Node.js 22 运行核心测试（跳过 Mac 原生测试）；macOS 15 上使用 Xcode 26.3 运行构建与产物核验，检查面向 macOS 13 及以上版本的 arm64 与 x86_64 通用构建及其成对语言资源。

CI 不会实际操作 App 界面或剪贴板，也不会在 macOS 13 系统上运行 App。涉及界面的改动，请在 PR 中说明手动检查情况，并在适用时附上截图。

## English

You are welcome to improve Flash Mask through bug reports or pull requests. Keep each pull request focused on a clear change and explain the problem it addresses.

Run the checks relevant to your change when practical:

- Core tests require Node.js 22: run `npm ci --ignore-scripts`, then `npm test`.
- The universal Mac app build requires a Mac with Xcode: run `./build.sh`, then `bash .github/scripts/verify-mac-build.sh` to verify the result. It creates an unsigned local app; no Apple signing certificate is needed, and the app is not distributed.
- Run local Mac UI tests separately with `node --test tests/mac-localization-ui.js`. They open an isolated test window and use synthetic images, separate preferences, and an intercepted clipboard. They are excluded from the default `npm test` and CI checks.

GitHub Actions runs two checks for pull requests targeting any branch, pushes to `main`, and manual dispatches: core tests on Ubuntu 24.04 with Node.js 22 (skipping Mac native tests), and a build and artifact verification on macOS 15 with Xcode 26.3 to check the arm64 and x86_64 universal build for macOS 13 or later and its paired localization resources.

CI does not exercise the app's GUI or clipboard, and it does not run the app on macOS 13. For UI changes, describe any manual checks in the pull request and include screenshots when applicable.
